## Headline (revised)

1. **Lead cell: `gc3t_mom6`, 112 T per logical W8 weight against 160 T (-30 %), 229,376 against 327,680
   cell transistors per R8 x C256 tile.** 4T gain bit + 3T crosspoint (one TG + one NMOS ground leg; the row
   driver resets the line, so the third TG goes). It works with the repo's sign-steering differential.
   Joint frame: ARCH 67,969 / 11.24 / 630 / 630 against the pick's 67,760 in the same snapshot (+0.3 %);
   Sohu identical (67,484 coarse grid, 80,773 fine grid). Core frame 48,830 against 48,831.
2. **LOUD CORRECTION of my round-2 draft: the 80 T/weight `gc_cs` claim is void for this repo.** The
   repo's diff is sign steering (N3.md: "sign rides the +/- lines"; 7 units per 4-b slice = 3 magnitude
   bits + sign), so the two columns hold independent bits and cannot share one. The code now shares a bit
   only when `w_enc == "complement"`, and then charges the honest 15 units per slice. Priced that way,
   `gc_cs` + complement scores 33,774 ARCH (area 30.6k um2 per tile): **dominated**. Under the default
   encoding `gc_cs_mom6` is now identical to `gc3t_mom6`.
3. **Why the cell barely moves tok/s: the caps bind** (critic upheld). Storage FEOL and MOM BEOL are
   within 1 % of each other, so cutting FEOL hands the binding to the MOM. With gc3t's FEOL down, a smaller
   LSB unit now pays: **r2_A4_best = gc3t_mom6 + `f_cu_lsb` 0.2: ARCH 68,890 / 10.88 / 613 / 629 (+1.7 %

   grid; tie).** It keeps the pick's 12-b converter (182.7 dB Schreier), so it adds no converter risk.
   The new risk is the 0.2 fF unit (= `unit_cap_min_fF`, A4-V2). Core frame (no N4 LSB hook): 48,830 /
   11.10 / 643 / 647 ARCH, 61,896 / 11.25 / 74.6 / 75.2 Sohu, a tie with the pick.
4. **The 11-b "+25 % TOPS/W" result is a converter-FoM relaxation, not a cell or bit-count result**
   (critic upheld, my draft corrected). r2_A4_fom11 (Cu 1.1, 11 b, the draft's `r2_A4_best`) needs
   9.41 ENOB at 664 MS/s in 95.9 fJ: **185.6 dB Schreier, 2.9 dB further past the envelope than the pick's

## Cell anatomy and counts

The repo's differential is sign steering (P = w+, N = w-; the sign rides the +/- lines), so each column
of the pair stores its own bits. Lead cell `gc3t`:

- **Bit (4T, one per column-bit):** write FET (nmos_sram, 1 fin, WWL boosted to 1.0 V for a write, -0.15 V
  hold), SRAM-Vt inverter (node S -> S-bar), read FET for refresh, **gated by S-bar** (the inverter output),
  so it does not load the storage node (critic item 7: the decks' 5-gate load on S is then the full load).
- **Crosspoint (3T):** a TG from the row line X to the cap bottom plate (n gate S, p gate S-bar) plus an
  NMOS ground leg (gate S-bar). Reset needs no third TG: the row driver returns X to 0 V (N9 interaction).
- **Totals.** Per logical weight: 2 columns x 8 x (4 + 3) = 112 T (229,376 per R8 x C256 tile).
  Round 1: 2 x 8 x (4 + 3 x 2) = 160 T. `gc_cs` (one bit per pair) would be 80 T, but only with complement
  bits: `w_enc == "complement"`, 15 units per 4-b slice, dominated (see the options table).
- **FEOL** per column-weight (gc3t): wb x (A_bit + 1.5 A_TG) x 1.3 = 8 x (0.0874 + 0.0656) x 1.3 = 1.59 um2
  (round 1: 2.274). BEOL MOM: (7 Cu + 15 f_lsb Cu) / rho = 2.249 um2 at Cu 1 fF, f_lsb 0.25 and
  rho 4.78 fF/um2, which binds; at f_lsb 0.2 it is 2.09 um2, still above the gc3t FEOL, which is why the
  LSB-0.2 step pays with gc3t and not with the round-1 cell.
- **Write path:** one WBL per column-bit (as round 1). 0.52 fJ per '1' write measured, 0.70 budgeted.

## Equations (in `n3_cell.py`)

- Retention, `t_ret_v2_us`: `t = integral C_node dV / I_net(V)`, with C_node = 5 x Cgg(1 fin) + C_j =
  0.31 fF, on the **measured** net node current with the 5-gate load (the read FET hangs on S-bar).
  - '1' runs from the write level down to V_MIN1 = **0.58 V** (TG dead zone, from-0 settling criterion,
    valid because the row driver resets the plate to 0 V every slot).
  - Design write level = min over {SS, TT} x {0, 27, 85} C (wr2.py): 0.636 V (SS 85 C) for the two 85 C
    leak tables (nominal and 6-sigma write FET), 0.608 V (SS 0 C) for the cold case on the 27 C table (gate
    tunnelling, the '1' limit, is nearly temperature-flat; subthreshold is lower cold, so conservative).
  - '0' runs from V_WRITE0 = -0.072 V up to V_MAX0 = 0.20 V.
  - Design value = min over those three cases and both states. A state that leakage pushes back into its
    window holds.
- Refresh: `P_ref = wb x E_ref / t_ret / pair` with `E_ref = E_wr + ½ C_RBL V² + E_SA`;
  occupancy = `2 R t_row / t_ret`.
- Crowbar: the inverter supply current, averaged over the droop range actually used,
  [0.7 − V_WRITE1(85 C), 0.7 − V_MIN1] = [0.055, 0.12] V (widest window, conservative), then x ½ x 0.7 V / pair.
- Row write (v2): `t_row = 2 FO4_lib(V) + max(5 τ_WBL, 45.3 ps)`. FO4_lib = 18.3 ps x FO4(V)/FO4(0.7).
  45.3 ps is the write FET's 99 % time, measured at SS.
- Sharing (`_pair_shared`) needs `topo == "diff"` AND `w_enc == "complement"`; complement charges
  2^b - 1 units per slice in `_units`. Otherwise `gain_cs` is exactly `gain_3t` (112 T/w). The self-check
  asserts 160 / 112 / 80 T/w, 14 against 30 units, and the doubled BEOL.
- Area: `max(FEOL, BEOL) / (1 − occ)` as in round 1. N4's `tile_effects` rescales BEOL by its
  asymmetric-LSB factor.

## Quality gate

Cell changes do not touch G1. G2 is the evaluator's SNR against 39.78 dB, with the same measured-only
credits as the pick (Hadamard 4.5 dB, class weight +3 dB, both inherited and both contested by the N8
critic). TT margins: `r2_A4_cell` and `r2_A4_best` +0.055 dB (same as
the pick), `r2_A4_fom11` **+0.030 dB**, `r2_A4_safe` +0.139 dB. No candidate here has SS or FF corner
closure; the pick does not have it either (assumed 0.89x). What each needs to pass the full gate:

- the pick's own items V1-V5;
- r2_A4_best: A4-V2 (0.2 fF unit and the 1:16 merge); nothing new on the converter;
- r2_A4_fom11 / r2_A4_safe: a converter at 185.5-185.6 dB Schreier (A4-V4), the top risk of this page;
- all: A4-V1 (column with the measured write level, dead zone, refresh at 2.08 us).

If the N8 settlement removes the +3 dB class weight, every row here fails, as the pick does. Robust
keeps its 2.33 dB only if it keeps its 11-b SAR and Cu 2 fF.

## What each option does to the other blocks

- **N5:** none for gc3t (works with sign steering, pseudo or diff). Pair sharing would need N5/N4 to adopt
  complement / offset-binary weights and pay 15 units per slice or an offset pedestal; priced, it loses.
- **N6:** take (adc_bits, cmp_noise_lsb, cu_fF) as one knob set; the Pareto rows above give margin and FoM
  per point. Every TOPS/W gain on this page above the pick's is FoM relaxation (1.8-2.9 dB), not a cell
  effect. The draft's "6 dB easier 11-b SAR" is withdrawn: the score's 11-b point is 185.6 dB against the
  pick's 182.7 dB.
- **N4:** `f_cu_lsb` 0.2 (from 0.25) sits at `unit_cap_min_fF`. The LSB slice's noise reaches the output
  at 1/16 amplitude (−20 dB), but 0.2 fF unit matching and the 1:16 merge ratio (V2) must hold.
- **N9:**
  - the row driver must return X to 0 V between slots (it replaces the cell's reset TG);
  - a WBL driver must idle at VDD;
  - the WWL must swing −0.15 → 1.0 V (charge pump plus boost: area and reliability not modelled);
  - the TG dead zone ties the drive levels to the refresh rate; it is worst cold, and the from-0 criterion
    makes the per-slot reset to 0 V a hard requirement.
  - The ref buffer (5.8k µm², 31 % of the tile) is now the largest non-weight block: the next area
    lever is there, not in the cell.
- **N7 / evaluator:**
  - the n9 clock grid {1.0, 0.5, 0.25} creates power-cap cliffs (the pick drops to x0.5 under Sohu, 67,484,
    while x0.95 gives 80,773). Please add 0.6-0.95 fractions or interpolate to the cap; Sohu numbers on this
    page are quoted on the fine grid;
  - `ret_model="v2"` is opt-in; flip `_B["ret_model"]` to "v2" once this round settles;
  - test_arch_eval.py: all PASS except the pre-existing "default design: four finite positive
    metrics" (the critic-noted infeasible DEFAULT, not caused by n3).
- **N1:** none. Refresh is local; writes are < 0.01 % of a load window.
