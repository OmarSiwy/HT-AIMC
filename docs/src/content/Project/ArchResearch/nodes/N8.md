`scripts/compiler/metrics/arch_eval/nodes/n8_quality.py`.
Labels: **M** = measured in this repo (numpy emulation on real SmolLM2-135M weights and text),
**D** = derived (law fitted to or applied to measured numbers), **P** = projected (literature only).

### The gate (option `g43_lossless`)

- **G1, format: lossless tier, W8A8 class.** At Llama-3-8B: SmoothQuant W8A8 +2.3 %, FP8 ≈ 0
  (P, LIT_QUALITY §1). W4 belongs to the acceptable tier only, and only with GPTQ plus learned
  rotation (SpinQuant +6.6 %, QServe +9.1 %, P). It fails on the proxy even with GPTQ (M, F20).
- **G2, analog increment: KL ≤ 0.01 nats ≈ +1 % PPL** against the same format run digitally. KL is
  the quantity actually measured. In circuit terms:

      target = 10 log10(A / 1 %)  +  9.66 log10(L / 30)  +  1 dB cushion  −  counted lever credit
             = 43.0 (band 40.0–45.8, D) + 0.27 (L = 32, D) + 1 (P) − credit
      SNR_eff = class-weighted combination of n5's parts (table below)
      range:   n5 k_sigma ≥ ±32 σ clip-free (M), or the readout declares relative precision (adc_float)

- **G3, reported, not gating.** Top-1 agreement with the digital run. DEPTH_BUDGET measures
  96.6 % at 46 dB and 93.8 % at 43.3 dB (M). A ≥ 97 % bar needs about 47 dB (D,
  option `g47_top1_97`). That is 4 dB stricter than G2. The user sets this bar.
- **Fairness.** The baseline is scored with the candidate's own KV width
  (`n8_quality.baseline(wbits, kv_bits)`). Any training allowed for analog must also be allowed
  for the baseline (27k5).

Error-class weights (`CLASS_DB`, in dB added to the n5 part; + means gentler than fresh noise):

| class | n5 parts | weight | evidence |
|---|---|---|---|
| fresh additive | thermal, settle, coupling, row_coupling, injection, cap_nl, ref_droop, clip | 0 | the class the law was fitted on |
| quantization | adc | **+3.0** (band 0 to +5.4) | D: the quant-only row gives A = 0.58e4, i.e. +5.4 dB. One run with se of about 3 % PPL, so half is credited |
| per-cell static weight error | mismatch | **0** (bracket −3.6 to +7.0) | DEPTH_BUDGET 5b: a weight error is 7 dB gentler (1 sig. fig.). 5a: a frozen channel error is 3.6 dB worse. Unmeasured for this class |
| column-coherent static residual | row_gain (after cal, `cal_res`) | **−3.6** | M: DEPTH_BUDGET 5a, 2.30x KL |

### Honest negatives (loud)

1. **The shipped uniform 28 dB gate is not a quality gate.** It costs +32 % PPL (D) and +65 %
   measured at depth (DEPTH_BUDGET). The paper's per-class 28 dB attention / 38 dB FFN gate is
   +10.0 % by the law with the 8B MAC shares (D, `g_paper_28_38`). That is also outside every
   quality tier.
2. **A ±4 σ static range collapses the model at any resolution** (M: adc 8–10 b at ±4 σ gives
   +356 to +361 %). ±16 σ still costs about +3 % from clipping. ±32 σ is clip-free. These are
   per-layer sigmas on per-token-scaled operands. n5's `k_sigma` acts on block-scaled columns, and
   that mapping is unmeasured.
3. **Rotation is necessary on every stack tried.** Raw operands top out at 31.5 dB (22:30) and
   43.8 dB (23:05). Every raw-operand option either fails or scores below 53 tok/s/die.
4. **The core self-test's "default design: four finite positive metrics" check fails, and the
   failure is correct.** The composed node defaults (n5 k_sigma 16, R8, 8 b) are not clip-free
   under the gate (32 σ). Earlier in this run n6's 8 b sentinel also made "no tile fits"; that has
   since cleared. The passing points are those in the table above.
5. **No per-cell predistortion rescue.** The per-cell mismatch error at 42.9 dB is about 0.32 LSB
   rms of the 8-bit weight. Correcting it with 1-LSB codes leaves the 1/12 LSB² rounding residual,
   which buys only +0.8 dB (D).

## 2. SNR to perplexity law (D, from M)

    dPPL_analog [%] = A · 10^(−SNR_dB/10),   A = 2.0e4 central, band 1.0e4 – 3.8e4
    +1 % → 43.0 dB (40.0 – 45.8),  +3 % → 38.2,  +10 % → 33.0
    depth: + 9.66 log10(L/30) dB  (32 layers +0.27, 80 layers +4.11)

| source (M) | SNR dB → increment | implied A | variance |
|---|---|---|---|
| DEPTH_BUDGET KL, 30 layers | 40 → KL 0.0223 ± 0.0008; 46 → 0.0054 | 2.1–2.2e4 | low: **central** |
| DEPTH_BUDGET PPL ratios | 40 → x1.0273; 43.3 → x1.0141; 46 → x1.0096 | 2.7–3.8e4 | one 256-token passage, no CI |
| quality.py, W8A8 4b slices R128 | 38.4 → +1.3 %; 28.0 → +16.2 % | 0.9–1.0e4 | single run, se ±1.5–3 % PPL |
| quality.py 32 σ ADC10 (quantization only) | 34.9 → +1.9 % | 0.6e4 | basis for the +3 dB adc weight |

The central A comes from the KL estimator, which has a 4 % relative se at 40 dB, and it sits at
the geometric middle of the band. Neither band end can certify a lever: the harness needs
paired-difference se ≤ 0.3 % PPL (≥ 5 seeds or passages) before any credit counts as M. Below
about 25 dB the law underpredicts (collapse).

## 3. Gate equations (`n8_quality.gate(p, acc, fmt)`)

    parts'   = n5 parts_db + CLASS_DB weights;  mismatch += q_mismatch_credit_db
               (no k_sigma in params: ADC −= 20 log10(clip/4), the frozen ±4 σ assumption)
    SNR_eff  = −10 log10 Σ 10^(−parts'/10)
    target   = q_snr_target + 9.66 log10(q_layers/30) − q_credit + q_die_margin
    passed   = SNR_eff ≥ target AND (k_sigma ≥ q_clip_sigma OR adc_float) AND wbits/abits ok
    reported: dppl_pred (A central) and dppl_band (A band ends)

`n8_quality.evaluate` moves `q_rail_macs_frac` of the weight MACs onto the digital rail through
`wl["att_macs_*"]` and removes the same amount from the tiles' load. The useful MAC count is
unchanged, so the charge is neutral. Per-tile and dynamic ranges add one rail rescale per column
partial (2/R of MACs). `best()` sweeps every streaming n1 option × rows {32…256} × share
{4, 8, 16} × ADC bits {8…14} × cu {1, 4, 16, 64} fF × MOS fins {8, 32, 128}, sweeping both because
n3 options read one or the other. It skips designs that n2 marks `kind='digital'`, since those are
out of analog scope, and sets `q_layers` from the workload. Split options run one search per
tensor class and combine them harmonically by MAC fraction (D).
Raw outputs: scratchpad `n8/live5.txt` (22:30, all options), `n8/live6.txt` (23:05, key options),
`n8/live6_sohu.txt`.

## 6. One-time cost and break-even (27n3)

`N_break = E_adapt / ΔE`, where ΔE is the saving the adaptation itself enables on the analog
design:
- Bundle calibration and permutation take about 1 GPU-h (P).
- HWA distillation: 4.6e4 V100-h × 300 W = 5.0e10 J. Its own saving is bundle_lead
  (343.4 tok/J) vs bundle_hwa (377.6 tok/J), ΔE = 0.26 mJ/token, so **N_break = 1.9e14 tokens**
  (D). Dominated.
- One-time GPU-h is reported as a separate unranked column (`q_gpu_h`). It is not in the four
  metrics.

## 7. Interactions

- **N3 / N5 / N6 (decisive).** The stack's throughput sets the outcome, not the gate. At the passing
  points the ADC term binds (38.5–39.7 dB at 32 and 8 σ). Raising converter ENOB at wide range, or a
  relative-precision readout (`adc_float`: float, companding or overflow fallback), is worth more
  than any N8 constant.
- **N6.** The range is ±32 σ, or ±8 σ with dynamic per-block FS (P). The per-token reference-DAC
  settle is unpriced.
- **N3.** On MOS-cap options mismatch follows `mos_fins`. On MOM options it follows `cu_fF`. Both
  are swept.
- **N4.** G1 forces W8. Keep `f_crest`/SQNR_req in step with `q_clip_sigma` and the target.
- **N7.** Side paths: 0.78 % protected tensor + 0.25 % rotation + 0.4 % dynamic FS + 2/R rescales.
- **N1.** W8 doubles streamed bytes.
- **N10 / fairness.** KV8 and any training apply to the baseline too.

## 8. What a wrong choice here costs

- **Too loose (uniform 28 dB, ±4 σ).** +32 to +360 % PPL: a collapsed model.
- **Too strict (G3 47 dB).** A 4 dB stricter target with no PPL gain. Choose it only if
  token-identical output is a requirement.
- **A credit that does not hold.** bundle_lead has a margin of only 0.14 dB. If the 4.5 dB Hadamard
  credit falls to 3 dB, the bundle needs about +1 ADC bit.

## 9. Falsifiers and sim requests (harness deferred by the user)

1. One joint run: W8A8 + Hadamard × ADC FS {8, 16, 32} σ (static per-layer, per-tile, dynamic
   per-block) with noise sized to 38–43 dB, 5 seeds, paired. It decides the 4.5 dB credit and
   clip 8 σ. **If the credit is < 3 dB or the dynamic 8 σ range costs > +0.5 %, bundle_rot_dfs falls
   back to bundle_lead.**
2. Per-class error injection at 38–43 dB, measured separately for each class (fresh, quantization,
   per-cell static, column residual). It sets `CLASS_DB`.
3. The KL share of each tensor class after rotation. It decides the protect-tensor and
   water-filling credits.
4. Calibration residual drift: column gain tempco × ΔT after a one-time calibration, plus a replay
   of the `csnr_holdout` per-column residual. Either could exceed the 1 dB cushion.
5. Comparator metastability and CM-to-DM error at 12 b.
6. Top-1 agreement at the gate, against the digital W8A8 run's own top-1 spread.
